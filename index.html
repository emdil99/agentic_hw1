Studio Rx

A planning assistant for Pilates instructors. Tell it about a client's medications and conditions, and it checks FDA drug labels for exercise cautions, builds a safe class plan, and suggests modifications.

What it can do

  • Check a medication Reads the FDA label for side effects that matter in class, like dizziness or a slowed heart rate.
  • Build a class plan Picks mat exercises that fit the time and level and skips ones unsafe for the client's conditions.
  • Modify an exercise A safer or easier version of a specific exercise.

Try asking

Studio Rx is a teaching aid, not medical advice. Discuss medication concerns with the client's healthcare provider.
